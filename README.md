# ОЙМ Ногоон Урлан — вэб сайт

Дөрвөн эх файлаас (`master CATALOGY`, `Presentation Oim 02.06`,
`ОЙМ Logo Guideline V5`, `Brainstorm - Green 100`) бүтээв.

## Файлын бүтэц

| Файл | Тайлбар |
|---|---|
| `index.html` | Бэлэн сайт. Ямар ч static hosting дээр `assets/`-ийн хамт байрлуулна. |
| `oim-standalone.html` | Бүх зураг нь дотор нь шигтгэгдсэн ганц файл (offline, имэйлээр илгээхэд). |
| `index.src.html` | Эх загвар. `__MARK__`, `__WORD__`, `__PLANTS__`, `__PROJECTS__` орлуулагчтай. |
| `styles.css` | Брэнд систем — өнгө, үсгийн хэв, бүх компонент. |
| `app.js` | Дэлгүүрийн логик — шүүлтүүр, эрэмбэ, дэлгэрэнгүй цонх, сагс, түрээсийн таб. |
| `build.py` | `index.src.html` → `index.html` (+ `--inline` → `oim-standalone.html`). |
| `assets/` | Зураг (WebP), лого (SVG), өгөгдөл (JSON). |
| `assets-lite/` | Жижигрүүлсэн хувилбар — зөвхөн `oim-standalone.html` бүтээхэд. |

## Дахин бүтээх

```sh
python3 build.py            # index.html
python3 build.py --inline   # + oim-standalone.html
```

## Хуудасны бүтэц

Сайт нь нэг файлд байрлах ч **хаяг бүхий 7 хуудастай** (hash router, `app.js` доторх
`show()` / `routeName()`). Нүүр хуудсанд каталогийн бүтэн жагсаалт болон үнийн
хүснэгтүүд **байхгүй** — зөвхөн товч танилцуулга байх ба холбогдох цэсээр орно.

| Хаяг | Цэс | Агуулга |
|---|---|---|
| `#/` | лого дээр дархад | Hero, давуу тал, ангилал, онцлох 8 ургамал, тохижилт/түрээсийн товч, **үйлдвэрлэл**, бахархал, төслийн товч, харилцагч, холбоо барих |
| `#/shop` | Дэлгүүр | 71 ургамлын бүтэн каталог, шүүлтүүрийн самбар, сагс |
| `#/care` | Арчилгаа | Зурагтай 4 зарчим, “орчиндоо тохирсон ургамлаа ол” |
| `#/services` | Тохижилт | 7 үйлчилгээний м²-ийн үнэ |
| `#/rental` | Түрээс | Амьд / хиймэл таб, тариф, тээвэр, нөхцөл |
| `#/projects` | Төслүүд | Онцлох ажлууд, 30 зургийн галерей, харилцагч |
| `#/contact` | Холбоо барих | Утас, и-мэйл, вэб, сошиал |

Цэсэнд “Нүүр” гэсэн тусдаа мөр байхгүй — толгой болон хөлний лого нүүр рүү буцаана.
Хуудас солиход гарчиг (`document.title`) солигдож, дээшээ гүйлгэнэ. Хөтчийн
“буцах” товч ажиллана. Шинэ хуудас нэмэхдээ `index.src.html`-д
`<div class="view" data-view="…" hidden>` нэмээд `app.js`-ийн `TITLES`-д мөр нэмнэ.

## Арчилгааны заавар

Каталогийн **71 ургамал бүрд** арчилгааны заавар байгаа. Ургамал дээр товшиход
дэлгэрэнгүй цонхонд гэрэл / усалгаа / арчилгааны түвшин / температур гэсэн дөрвөн
үзүүлэлт, дараа нь бэлгэдэл, усалгааны горим, байршлын тайлбар гарна.

Эх сурвалж хоёр төрөл, `plants.json`-ы `care.src` талбарт тэмдэглэсэн:

| `care.src` | Тоо | Утга |
|---|---|---|
| `oim` | 28 | ОЙМ-ийн үнийн саналын дэлгэрэнгүй хуудаснаас үгчлэн авав (14 бичвэр, хэмжээний хувилбаруудад нь мөн хамаарна) |
| `guide` | 43 | Тухайн зүйлийн ерөнхий шаардлагад тулгуурлан бичив — **хянаж баталгаажуулах шаардлагатай** |

`guide` төрлийн бичвэрүүд нь [`care-guides.py`](care-guides.py) файлд 25 зүйлээр
бүлэглэн хадгалагдсан. Засвар оруулбал дараах байдлаар дахин нэгтгэнэ:

```sh
python3 care-guides.py     # эх бичвэрүүд
# засаад plants.json-г шинэчлэх скриптээ ажиллуулна
```

`#care` хэсэг нь зурагтай дөрвөн үндсэн зарчим, доор нь “орчиндоо тохирсон ургамлаа ол”
гэсэн дөрвөн хавтас — товшиход каталог тухайн шаардлагаар шүүгдэнэ.

## Дэлгүүрийн шүүлтүүр

Зүүн талын шүүлтүүрийн самбар нь дөрвөн бүлэгтэй, олон сонголт зэрэг идэвхжинэ:

* **Ангилал** — навчит / цэцэглэдэг / мөлхөө / үрсэлгээ
* **Хэмжээ** — ТОМ / ДУНД / ЖИЖИГ / үрсэлгээ
* **Үнэ** — 15,000₮ хүртэл / 15–50 мянга / 50–300 мянга / 300 мянгаас дээш
* **Гэрлийн шаардлага** — тод гэрэл 27 / шууд бус 33 / сүүдэрт тэсвэртэй 11
* **Усалгааны хэрэгцээ** — бага 19 / дунд 40 / их 12
* **Арчилгааны түвшин** — хялбар 43 / дунд 20 / нарийн 8

Идэвхтэй шүүлтүүр бүр каталогийн дээр талбайд chip болж харагдана, дарж хасна.
1000px-с бага дэлгэц дээр самбар нь “Шүүлтүүр” товчоор нээгддэг хажуугийн цонх болно.
Үнийн ангиллыг `app.js` доторх `PRICE_BANDS`-с өөрчилнө.

## Ажилтны портал (`portal/`)

Хөлний **“Ажилтны портал”** товч нь `website/portal/` сан руу заана. Тэнд
`~/Downloads/ceo-dashboard-2026` (`oim-dashboard`, Next.js) төслийн **статик
экспорт** байрладаг тул тусдаа сервер шаардахгүй — сайттай хамт нэг хостод
байршина.

### Дахин экспортлох

```sh
cd ~/Downloads/ceo-dashboard-2026
NEXT_PUBLIC_BASE_PATH=/portal npx next build      # → out/
rm -rf ~/Documents/OIM/website/portal
cp -R out ~/Documents/OIM/website/portal
```

`NEXT_PUBLIC_BASE_PATH` нь `next.config.ts`-ийн `basePath` болон логоны замыг
хоёуланг нь удирдана. Өөр дэд зам сонговол (жишээ нь `/admin`) энэ хувьсагч
болон `app.js`-ийн `PORTAL` тогтмолыг хамт солино.

### ⚠ Нэвтрэлтийг Firebase рүү шилжүүлэх

Портал одоо **дотоод горимд** ажиллаж байна — `src/data/users.ts` доторх
`oim` / `oim123!` нууц үг браузерын багц дотор **ил** очдог. Интернэтэд
гаргахаас өмнө заавал:

1. console.firebase.google.com → төсөл үүсгэх
2. Authentication → Sign-in method → **Email/Password** → Enable
3. Users → ажилтан бүрт хэрэглэгч үүсгэх
4. Project settings → Your apps → Web → `firebaseConfig`-оос 6 утгыг
   `~/Downloads/ceo-dashboard-2026/.env.local`-д бөглөх (`.env.example`-г хуулна)
5. Дахин экспортлох. Нэвтрэх дэлгэц дээрх “Дотоод горим” анхааруулга алга болно.
6. `src/data/users.ts` доторх жагсаалтыг хоослох.

### Ганц файлын хувилбар

`oim-standalone.html`-д портал байхгүй тул `build.py` нь тэр хувилбараас
портал холбоосыг автоматаар хасдаг.

## Сагс — худалдан авах / түрээслэх

Сагсанд **Худалдан авах** ба **Түрээслэх** гэсэн хоёр горим бий.

Түрээслэх горимд сагсны нийт дүнг ургамлын үнийн дүн болгон авч, сонгосон
хугацааны тарифаар түрээсийн төлбөрийг бодоод, барьцаа төлбөрийг нэмж
**төлөх дүн**-г гаргана. Дараа нь **түрээсийн 7 нөхцөл** задарч гарах бөгөөд
зөвшөөрөх нүдийг тэмдэглэх хүртэл “Түрээсийн хүсэлт илгээх” товч идэвхгүй
байна. Идэвхгүй товч дархад анхааруулга гарч, зөвшөөрөх нүд рүү анхаарал татна.

Илгээх и-мэйлд ургамлын жагсаалт, хугацаа, түрээсийн төлбөр, барьцаа, нийт дүн
болон “Түрээсийн нөхцөлтэй танилцаж, зөвшөөрсөн” тэмдэглэл автоматаар орно.

Нөхцөлийн эх бичвэр `app.js`-ийн `RENT_TERMS` массивт, тарифын хувь `CART_DUR`-д байна.

## Messenger холбоос

“Үнийн санал авах” бүх товч Facebook хуудасны Messenger руу шууд шилждэг.
Хаягийг `app.js`-ийн эхэнд **ганц мөрөнд** тодорхойлсон:

```js
var MESSENGER = 'https://m.me/oimnogoonurlan.mn';
```

`data-messenger` атрибуттай элемент бүрт энэ хаяг ачаалах үед автоматаар онооно.
Facebook хуудсаа солибол зөвхөн энэ мөрийг засна.

> **Шалгах шаардлагатай:** хайлтаар хоёр хуудас олдсон —
> `facebook.com/oimnogoonurlan.mn` (и-мэйлийн домэйнтэй тааруулж сонгосон) ба
> `facebook.com/Oim.Nogoon.Urlan`. Аль нь албан ёсны идэвхтэй хуудас болохыг
> баталгаажуулна уу.

## Түрээсийн хэсэг

`#rental` хэсгийг орчин үеийн үнийн хуудасны загвараар зохиов:

1. **Хугацааны сегмент товч** (1–10 хоног / 11–30 хоног / 1–3 сар) — хуудасны
   бүх үнийг зэрэг шинэчилнэ.
2. **Хоёр тариф карт** (Амьд / Хиймэл) — сонгосон нь тодруулагдана.
3. **Урьдчилсан тооцоолуур** — ургамлын үнийн дүн эсвэл хананы м², бүс,
   тээвэрлэлтийг оруулбал түрээс + тээвэр + суурилуулалтыг задлан бодож,
   нийт дүн болон барьцааг шууд харуулна.
4. **Бүх тариф** нь `<details>` дотор эвхэгдсэн — шаардвал л нээнэ.

### Фонт

Брэнд бүүкийн 10-11-р хуудсанд **TT Norms Pro** (үндсэн), **SF Rounded** (туслах)
гэж зааж өгсөн. Гэвч аль аль нь вэбэд ашиглах боломжгүй:

* **TT Norms Pro** — TypeType студийн худалдааны фонт. Google Fonts дээр байхгүй,
  зөвхөн [typetype.org](https://typetype.org) эсвэл MyFonts/Fontspring-ээс вэб
  лиценз худалдаж авна.
* **SF Rounded** — Apple Developer-ээс татагдах ч лиценз нь зөвхөн Apple-ийн
  платформд хязгаарлагдана. Вэб сайтад ашиглахыг хориглодог.

Тиймээс бүх текстэд **Montserrat** (Google Fonts, кирилл бүрэн) ашиглав.

Хожим TT Norms Pro-ийн вэб лиценз авбал `.woff2` файлыг `assets/`-д хийж,
`styles.css`-ийн эхэнд `@font-face` тодорхойлоод `--f-display`-г солиход хангалттай:

```css
@font-face{font-family:"TT Norms Pro";src:url("assets/ttnormspro.woff2") format("woff2");
  font-weight:100 900;font-display:swap}
:root{--f-display:"TT Norms Pro","Montserrat",Arial,sans-serif}
```

Лого (тэмдэг + ОЙМ бичвэр) нь PDF-ээс гаргасан **вектор SVG** тул фонтоос
хамаарахгүй — брэнд бүүктэй үргэлж яг таарна.
